# Workflows

Markdown SOP súbory definujúce procesy projektu "Hra".

Každý workflow obsahuje:
- **Objective** – čo chceme dosiahnuť
- **Inputs** – čo potrebujeme na vstupe
- **Tools** – ktoré skripty z `tools/` použiť
- **Steps** – postup krok za krokom
- **Outputs** – čo je výsledkom
- **Edge cases** – ako riešiť problémy
